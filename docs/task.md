GEO/LEOがCR3BPのSALIでカオス判定される原因
問題
GEO・LEOは地球近傍の軌道であり、太陽の重力摂動は微小なため、本質的に二体ケプラー運動（非カオス）である。 にもかかわらず、太陽-地球系CR3BPの回転座標系でSALIを計算すると、カオスと判定される。

原因の全体像
根本原因はCR3BPの回転座標系における変分方程式の構造にある。 二体的な軌道を回転座標系で記述し変分方程式を解くと、偏差ベクトルが周期的に一時整列し、SALIが振動的に低下する。これは真のカオス（不可逆的な整列）ではなく、偽陽性である。

原因の詳細
1. 時間スケールの極端な分離
変分方程式のヤコビ行列は以下の構造を持つ：

$$\frac{d}{dt}\begin{pmatrix}\delta\mathbf{r}\\delta\mathbf{v}\end{pmatrix} = \begin{pmatrix}O_3 & I_3\\nabla^2 U(\mathbf{r}(t)) & C\end{pmatrix}\begin{pmatrix}\delta\mathbf{r}\\delta\mathbf{v}\end{pmatrix}$$

ヘシアン $\nabla^2 U$: $r_2^{-3}$ ～ $r_2^{-5}$ に比例する項を含み、地球近傍で巨大（LEOで $O(10^{10})$）。軌道周期で高速変動する
コリオリ行列 $C$: 定数で $O(1)$（系の回転角速度に対応）
この2つが偏差ベクトルの速度成分に加法的に作用する：

$$\delta\dot{v}x = \underbrace{2\delta v_y}{\text{コリオリ（定数）}} + \underbrace{U_{xx}\delta x + U_{xy}\delta y + U_{xz}\delta z}_{\text{ヘシアン（高速振動）}}$$

2. ヘシアンとコリオリの干渉によるビート的変調
ヘシアンが支配的な位相 → 偏差ベクトルは局所ケプラー運動の方向に沿う
コリオリが相対的に効く位相 → 偏差ベクトルが回転座標系の歳差方向に引っ張られる
この伸びやすい方向の周期的切り替わりにより、2本の偏差ベクトル $\hat{w}_1, \hat{w}_2$ が一時的に同方向へ揃う瞬間が生じる。

3. SALIの瞬間的低下
$$\mathrm{SALI}(t) = \min(|\hat{w}_1 + \hat{w}_2|, |\hat{w}_1 - \hat{w}_2|)$$

一時的整列時に $|\hat{w}_1 - \hat{w}2| \approx 0$ → SALI ≈ 0 となるが、その後方向が離れてSALIは回復する。 積分終了時刻 $t{\max}$ がこの振動の谷に一致すると、閾値以下の値をとり偽陽性となる？
